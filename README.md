# 📚 Flutter Assignment Manager

A simple and user-friendly **Assignment Manager mobile/web application built using Flutter and Dart**.  
The application helps students manage their assignments, track deadlines, and keep their academic tasks organized.

---

## 📌 About the Project

The **Assignment Manager** is designed to help students organize their academic assignments in one place.

Users can add assignments with important details such as title, description, subject, and due date. They can also track completed assignments and delete assignments when they are no longer required.

---

## ✨ Features

- ➕ Add new assignments
- 📝 Enter assignment title and description
- 📚 Add subject/category
- 📅 Select assignment due date
- ⏰ Track assignment deadlines
- ✅ Mark assignments as completed
- 🗑️ Delete assignments
- 📋 View all assignments
- 🎨 Simple and attractive user interface
- 💻 Runs on Flutter-supported platforms

## 🚀 Getting Started

Follow these steps to run the project on your computer.

### 1. Clone the Repository

```bash
git clone https://github.com/YOUR-USERNAME/YOUR-REPOSITORY.git
```

### 2. Open the Project

```bash
cd assignment_manager
```

### 3. Install Dependencies

```bash
flutter pub get
```

### 4. Run the Application

For Chrome:

```bash
flutter run -d chrome
```

For Windows:

```bash
flutter run -d windows
```

---

## 📱 How the Application Works

### Step 1: Open the Application

The home screen displays the assignment manager interface.

### Step 2: Add an Assignment

Enter the required assignment information:

- Assignment title
- Description
- Subject
- Due date

### Step 3: View Assignments

All added assignments are displayed in the assignment list.

### Step 4: Complete an Assignment

Once an assignment is finished, mark it as completed.

### Step 5: Delete an Assignment

Assignments that are no longer needed can be deleted.
